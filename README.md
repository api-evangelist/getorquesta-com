Orquesta provides an autonomous business platform that enables teams to build self‑running companies with AI‑driven agents. The platform offers a mesh of autonomous agents that collaborate, hand off work, and execute tasks across product, control, and team functions. Users can self‑host or use cloud services, integrate with popular tools, and customize workflows via a robust API and CLI. Orquesta aims to streamline operations, reduce manual overhead, and empower organizations to scale efficiently with AI assistance.

**Areas:** AI · Automation · Business · Platform · Orchestrator

## Orquesta on APIs.io

Everything profiled for Orquesta is published on APIs.io rather than in this repository. Start at the provider page — **[apis.io/providers/getorquesta-com/](https://apis.io/providers/getorquesta-com/)** — or go straight to one of the APIs or properties below.

### APIs (8)

- [Orquesta Agent Mesh API](https://apis.io/apis/getorquesta-com/getorquesta-com-agent-mesh-api/) — Who may ask whom inside an organization, as code: export a declarative document, edit it, plan (a diff that changes nothing) and apply. Needs an org API key…
- [Orquesta Agents API](https://apis.io/apis/getorquesta-com/getorquesta-com-agents-api/) — Registered agent installations and their online status.
- [Orquesta Batuta LLM API](https://apis.io/apis/getorquesta-com/getorquesta-com-batuta-llm-api/) — OpenAI-compatible chat completions proxy with smart per-prompt model routing.
- [Orquesta Logs API](https://apis.io/apis/getorquesta-com/getorquesta-com-logs-api/) — Execution logs emitted by agents during a prompt run.
- [Orquesta Projects API](https://apis.io/apis/getorquesta-com/getorquesta-com-projects-api/) — Projects in your organization.
- [Orquesta Prompts API](https://apis.io/apis/getorquesta-com/getorquesta-com-prompts-api/) — Prompt execution records (one per CLI/agent/dashboard run).
- [Orquesta Users API](https://apis.io/apis/getorquesta-com/getorquesta-com-users-api/) — Members of the organization (or of the token's project, for agent tokens).
- [Orquesta Workstreams API](https://apis.io/apis/getorquesta-com/getorquesta-com-workstreams-api/) — Named streams of work inside a project (branch, directory, purpose), each bound to one agent.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Orquesta: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
